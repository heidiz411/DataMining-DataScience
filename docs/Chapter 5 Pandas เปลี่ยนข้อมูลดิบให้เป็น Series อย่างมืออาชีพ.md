### คู่มือเริ่มต้นใช้งาน Pandas: เปลี่ยนข้อมูลดิบให้เป็น Series อย่างมืออาชีพ

##### 1\. ทำความรู้จักกับ Pandas และโครงสร้างข้อมูลแบบ Series

ในเชิงคอมพิวเตอร์ การมีข้อมูลมหาศาลอาจไม่มีประโยชน์เลยหากเราไม่สามารถ "กรอง" หรือ "คัดเลือก" ส่วนที่สำคัญออกมาได้ Pandas จึงทำหน้าที่เป็นเครื่องมือในการเปลี่ยน  **ข้อมูลดิบ (Raw Data)**  ให้กลายเป็น  **สารสนเทศ (Information)**  ที่พร้อมใช้งานครับ**นิยามพื้นฐานที่ต้องรู้**

* **Pandas:**  Library ในภาษา Python ที่ถูกพัฒนาต่อยอดมาจาก NumPy เพื่อใช้จัดการและวิเคราะห์ข้อมูลทั้งมิติเดียวและหลายมิติ  
* **Series:**  โครงสร้างข้อมูลพื้นฐานที่สุด เปรียบเสมือน "อาร์เรย์ 1 มิติ" ที่มีความพิเศษคือประกอบด้วยคู่ของ  **Index (เลขดัชนี)**  และ  **Element (ข้อมูล)**  เสมอ**ตารางเปรียบเทียบโครงสร้างข้อมูลใน Pandas**| โครงสร้าง | จำนวนมิติ | ลักษณะเด่น || \------ | \------ | \------ || **Series** | 1 มิติ | ข้อมูลแถวยาวคอลัมน์เดียว (เหมือน List ที่มีป้ายกำกับ) || **DataFrame** | 2 มิติ | ตารางที่มีทั้งแถวและคอลัมน์ (เหมือน Excel หรือ SQL Table) || **Panel** | 3 มิติ | การนำ DataFrame หลายอันมาซ้อนกันเป็นชั้น (Layer) |

*เมื่อเข้าใจ Series แล้ว การขยับไปใช้ DataFrame ก็จะเป็นเรื่องง่าย เพราะ DataFrame คือการนำ Series หลายๆ เส้นมาวางเรียงต่อกันนั่นเองครับ*

##### 2\. การเตรียมตัวก่อนเริ่มเขียนโค้ด

ก่อนจะเริ่มแปลงร่างข้อมูล เราต้องติดตั้งเครื่องมือให้พร้อมก่อนครับ ในคู่มือนี้เราจะใช้ทั้ง Pandas และ NumPy ควบคู่กันไป

1. **การติดตั้ง:**  เปิด Terminal หรือ Command Prompt แล้วพิมพ์คำสั่ง:

* **pd และ np:**  ช่วยให้เขียนโค้ดได้รวดเร็วขึ้น และเป็นที่เข้าใจตรงกันของโปรแกรมเมอร์ทั่วโลก

##### 3\. พลังแห่งการแปลงร่าง: สร้าง Series จากข้อมูลประเภทต่างๆ

ไม่ว่าข้อมูลดิบของคุณจะมาในรูปแบบไหน Pandas พร้อมจะเปลี่ยนให้มันเป็นระเบียบได้ทันทีครับ มาลองดูตัวอย่าง "การแปลงร่าง" ข้อมูลกัน:

###### *3.1 สร้างจาก List และ Tuple*

เหมาะสำหรับข้อมูลทั่วไปที่เก็บไว้ในตัวแปรพื้นฐานของ Python  
import pandas as pd

\# สร้างจาก List (เก็บข้อมูลต่างชนิดกันได้)  
data\_ls \= \[10, "KongRuksiam", True, 25.5\]  
ps\_list \= pd.Series(data\_ls)

**Result:**  
0             10  
1    KongRuksiam  
2           True  
3           25.5  
dtype: object

###### *3.2 สร้างจาก NumPy Array*

นี่คือวิธีที่พบบ่อยในการทำงานจริง เพราะเรามักจะประมวลผลตัวเลขด้วย NumPy ก่อนแล้วจึงส่งต่อให้ Pandas  
import numpy as np

\# สร้าง NumPy Array ก่อน แล้วแปลงเป็น Series  
nd\_data \= np.array(\[100, 200, 300\])  
ps\_np \= pd.Series(nd\_data)

**Result:**  
0    100  
1    200  
2    300  
dtype: int32

###### *3.3 สร้างจาก Dictionary (เทคนิคพิเศษ)*

วิธีนี้  **ทรงพลังที่สุด**  เพราะ Pandas จะดึงเอา  **Key**  มาทำเป็น  **Index**  และเอา  **Value**  มาเป็น  **Element**  ให้เราทันทีโดยไม่ต้องตั้งค่าเพิ่มครับ  
data\_dict \= {"Apple": 50, "Banana": 20, "Grape": 30}  
ps\_dict \= pd.Series(data\_dict)

**Result:**  
Apple     50  
Banana    20  
Grape     30  
dtype: int64

**สรุปความแตกต่างของข้อมูลต้นทาง**| ประเภทข้อมูล | สัญลักษณ์ | ผลลัพธ์ใน Series || \------ | \------ | \------ || **List** |  | Index อัตโนมัติ (0, 1, 2...) || **Tuple** | ( ) | Index อัตโนมัติ (0, 1, 2...) || **Dictionary** | {K:V} | **Key กลายเป็น Index ทันที**  (ไม่ต้องสร้างเอง) |

##### 4\. การกำหนดหมายเลข Index ด้วยตนเอง (Custom Indexing)

หากคุณไม่ต้องการให้ Index เป็นตัวเลข 0, 1, 2... คุณสามารถกำหนด "ป้ายกำกับ" ให้ข้อมูลได้เอง เพื่อให้สื่อความหมาย (Semantic Index) ได้ชัดเจนขึ้น  
items \= \["มะม่วง", "กล้วย", "องุ่น"\]  
prices \= \[50, 20, 30\]

\# กำหนดให้ราคากลายเป็น Index ของชื่อสินค้า  
ps \= pd.Series(items, index=prices)

**Result:**  
50    มะม่วง  
20     กล้วย  
30      องุ่น  
dtype: object

**⚠️ กฎเหล็กที่ต้องจำ (Rule of Thumb):**   **จำนวนของ Index ที่คุณกำหนด จะต้อง "เท่ากับ" จำนวนข้อมูลเสมอ**  หากมีข้อมูล 3 ชุด แต่ใส่ Index 2 ตัว โปรแกรมจะแจ้งข้อผิดพลาด (ValueError) ทันทีครับ

##### 5\. กลไกการเข้าถึงข้อมูล (Indexing & Slicing)

เมื่อเราจัดระเบียบข้อมูลเป็น Series แล้ว การ "หยิบ" มาใช้งานก็ทำได้แม่นยำด้วยวิธีดังนี้:

1. **Indexing:**  เข้าถึงข้อมูลตัวเดียวด้วย psindex  
2. **Slicing:**  เข้าถึงข้อมูลเป็นช่วงด้วยหลักการ  **Start : Stop-1ตารางสรุป Syntax การ Slicing และผลลัพธ์**| Syntax | ความหมาย | ข้อมูลที่ได้รับ (ตัวอย่าง 10 รายการ) || \------ | \------ | \------ || : | เลือกทั้งหมด | ตำแหน่งที่ 0 ถึงตัวสุดท้าย || 2: | เริ่มจากตำแหน่งที่ 2 | ตำแหน่งที่ 2 ถึงตัวสุดท้าย || :3 | 3 รายการแรก | ตำแหน่งที่ 0, 1, 2 (หยุดก่อนถึง 3\) || 1:4 | เลือกช่วงที่กำหนด | ตำแหน่งที่ 1, 2, 3 (หยุดก่อนถึง 4\) |

**ตัวอย่างการเข้าถึงด้วย Label:**  ถ้าเราตั้งชื่อ Index ไว้ เช่น ps \= pd.Series(10, 20, index='A', 'B') เราสามารถพิมพ์ ps'A' เพื่อได้ค่า 10 มาใช้งานได้ทันทีครับ

##### 6\. บทสรุปและการประยุกต์ใช้งาน

การเข้าใจ  **Series**  คือหัวใจสำคัญครับ เพราะไม่ว่าข้อมูลจะซับซ้อนแค่ไหน พื้นฐานก็มาจากการจับคู่ข้อมูลกับตำแหน่ง (Index) ทั้งสิ้น เมื่อคุณคล่องแคล่วในการสร้างและดึงข้อมูลแล้ว คุณก็พร้อมจะไปลุยกับข้อมูลขนาดใหญ่ใน DataFrame ต่อไปแล้วครับ**🏅 Skill Badge: สิ่งที่คุณทำได้แล้วในตอนนี้**
